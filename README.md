# Sistema de Gestão de Brinquedos

Esse projeto é um sistema simples feito para organizar os brinquedos de uma loja. Nele é possível cadastrar, ver, alterar e excluir brinquedos.

Foi desenvolvido usando PHP, MySQL e HTML, sendo necessário utilizar o XAMPP para rodar o sistema.

A tela principal mostra os brinquedos cadastrados e possui um formulário para adicionar novos brinquedos. Também existem as opções de editar e excluir cada brinquedo quando necessário.
